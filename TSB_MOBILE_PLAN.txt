TSB MOBILE APP - BUILD PLAN
================================================================

Build the TSB website as a mobile app for Android and iPhone.
Server already exists. We build screens only.

Reference: webSrc folder (website code).

    NOTE ON PHASE 3
        Phase 3 is the largest and riskiest part of the app
        (17 post types). It builds the card system that
        Phase 4 and Phase 5 both reuse. Do not rush it -
        time saved here comes back as rework in Phase 4.

        - Designs are ready before each phase starts
        - Developer reviews work daily, not weekly
        - Backend is stable and answers come same day
        Any delay in these moves the end date directly.

PHASE 2 - THE 8 ROLE FORMS                   6 DAYS  (day 5-10)
================================================================

BUILD
    1. Role picker screen (8 role cards)
    2. Sign up form for each of the 8 roles
    3. Edit mode for the same forms
    4. Interests screen
    5. Location picker (country, state, city)
    6. Document upload
    7. Profile progress bar
    8. Shared UI parts used by all later screens
       (buttons, inputs, dropdowns, tabs, pop-ups, cards,
        badges, sliders, date picker, multi-select - about 20)

WHAT IS IN EACH ROLE FORM
    All 8 forms share the same 4 sections. Only the questions
    inside change per role.

        1. ORGANIZATION DETAILS
           Role at the organization, organization name,
           education level, field of study, years of experience

        2. ROLE PREFERENCES  (different for each role)
           Searcher      search stage, time commitment, equity
                         status, debt status, deal size range,
                         revenue and EBITDA range, background
           Investor      investment stage, ticket size,
                         investment preference, past deals
           Lender        loan types (term loan, revolving,
                         cash flow, acquisition, bridge,
                         refinancing, equipment, real estate,
                         working capital, mezzanine),
                         deal stage they fund
           Advisor       seniority, services offered (M&A,
                         due diligence, valuation, tax, legal,
                         integration), client types
           Operator      area of expertise, role type,
                         how they prefer to engage
           Seller        reason for sale, transition type,
                         involvement level, preferred buyer
                         type, transaction details
           Student       areas of interest (deal sourcing,
                         modeling, due diligence, research,
                         operations, marketing, legal)
           Intermediary  seniority, deal types handled

        3. INDUSTRIES AND GEOGRAPHY  (same for all 8)
           Industries of interest, geography focus,
           country / state / region

        4. MATCHMAKING
           Interests, matching preferences

    NOTE - checked the website code:
    8 sign-up forms are full forms.
    Only 3 edit forms are real (Advisor, Intermediary, and
    the shared one). The other 5 edit forms are 22-line
    wrappers that reuse the sign-up form.
    So this is 8 full forms, not 16.

    Build one form engine with 8 question lists, not 8
    separate screens.

DONE WHEN

      home screen - working for all 8 roles
    - User can edit answers later
    - Document upload works

PHASE 4 - CREATE POST AND DEAL FLOWS         6 DAYS  (day 18-23)
================================================================

BUILD
    MOVED FROM PHASE 3                               2 days
    1. Search and filter panel
    2. Single post screen with comments and replies
    3. All post buttons - like, save, comment, reply,
       share, report, hide, delete
       (Share to chat is NOT here. It needs chat to
        exist, so it is built in Phase 6.)

    CREATE POST                                      2 days
    4. Create post screen - what to ASK when creating
       each of the 17 post types
    5. Attach photos and files
    6. Save as draft
    7. Post anonymously

    DEAL AND ACTION FLOWS                            2 days
    8.  Poll    - vote, change vote, see results
    9.  Event   - RSVP, cancel RSVP
    10. Job     - apply, track status, withdraw,
                  accept or reject applicants
    11. NDA     - request, send, sign, decline, withdraw
    12. PPM     - request, send, sign, decline, withdraw
    13. CIM     - send document
    14. Express interest button

    HOW 6 DAYS WORKS - BUILD IT THIS WAY

    1. Create post reuses the settings list from Phase 3.
       Phase 3 already lists the fields for each post type.
       Here we only add what kind of input each field needs
       and its options. Not 17 new forms.

    2. NDA, PPM and CIM are ONE flow, not three.
       All three are the same 5 steps:
           request -> send -> sign
           (or decline, or withdraw)
       Build one flow and pass the document type into it.

    3. Poll, RSVP and Job apply are separate small pieces.

    IF THIS SLIPS, IT WILL BE THE NDA AND PPM FLOW.
    Each has 5 states and must show the correct screen to
    BOTH sides - the person who asked and the person who
    must respond. Test with two accounts, not one.

    ROLE RULES - checked in the website code:
    8 post types are the same for every role (Ask the
    Community, Investor Corner, Search Capital, Deal, Job,
    Event, Poll, FAE).
    Only "Find My Match" is role-specific. It has 8 versions
    and each user sees ONLY the one for their role.
    Build it as one form with 8 question lists.
    The composer must hide post types the user's role cannot
    create, or the server will reject the post.

PHASE 5 - PROFILE AND MATCHES                7 DAYS  (day 24-30)
================================================================

This phase builds where a member's identity lives, and the
matching system that connects them to other people.
Four parts.

----------------------------------------------------------------
PART A - MY PROFILE                                       2 days
----------------------------------------------------------------

WHAT THE USER SEES
    Cover photo, profile photo, name, role, headline, and
    their own posts listed below.

WHAT THE USER CAN FILL IN
    1. Profile photo and cover photo
    2. Education        - add, edit, delete
    3. Work experience  - add, edit, delete
    4. Current organisation
    5. Testimonials     - ask another member for a
                          recommendation, and show the ones
                          received
    6. Follow and unfollow, followers list, following list

WHY 2 DAYS IS ENOUGH - FOUR REUSES
    Own-posts list      = the Phase 3 feed component,
                          filtered to this user. Do not
                          rebuild it.
    Education, work experience and organisation
                        = ONE list-and-form component with
                          3 question lists. All three are the
                          same shape: a list plus add, edit
                          and delete. Do not build 3 times.
    Followers and following
                        = the same list twice
    Mini cards          = the Phase 3 card system

NO SEPARATE EDIT SCREENS
    The website has 4 extra edit pages. We do not need them:
        Pictures                - photo upload is above
        Account details         - in Settings, Phase 7
        Criteria and interests  - Phase 2 screen
        Dual profile management - Part C below
    Editing happens on the profile screen itself. That is
    the normal pattern on a phone.

----------------------------------------------------------------
PART B - THE 8 THESIS TABS                                3 days
----------------------------------------------------------------

WHAT A THESIS IS
    A detailed statement of what that person is looking for.
    Each of the 8 roles has its own version.

EXAMPLE - THE SEARCHER TAB ASKS
        Search type
        Search fund name
        Search fund website
        Incorporation year
        Years of experience
        Ownership preference
        Search thesis document (file upload)
        Search thesis summary
        Industry focus
        Geography focus

    The other 7 roles each have their own set.
    About 90 fields across all 8 tabs.

HOW TO BUILD IT
    ONE form engine with 8 question lists. Same as the role
    forms in Phase 2. Do NOT write 8 separate screens.
    On the website this is 9,259 lines. It only fits in
    3 days because the pattern repeats 8 times.

    The engine does not write the question lists. Someone
    must open each of the 8 website tabs, read every field,
    note its input type and options, and match it to the
    server. Roughly half a day per two roles.

    Each tab also has a file upload and its own completion
    percentage.

----------------------------------------------------------------
PART C - DUAL PROFILE                                     1 day
----------------------------------------------------------------

    Some members hold two roles - for example a Searcher who
    is also an Investor. They create a second profile and
    switch between them.

    Build: create, switch, delete.

    The switch is the fiddly part. Every screen has to reload
    as the other identity.

----------------------------------------------------------------
PART D - MATCHES                                          1 day
----------------------------------------------------------------

MY MATCHES - 3 TABS
        Suggested        people the system picks for you
        From My Posts    people who fit what you posted
        Where I'm a Fit  posts where you fit what they need

ALSO BUILD
    1. Match card - fit score and match status
       (New Match, Interest Expressed)
    2. Match detail screen - your fit for this post,
       pass button, send message
    3. Passed matches list
    4. Match settings - tune who appears in Suggested
       (minimum, maximum, accredited only,
        confidential posters)
    5. AI match analysis - generate and regenerate
    6. Other member's profile screen

WHY 1 DAY IS ENOUGH - THREE REUSES
    Passed list             = same list, different endpoint
    Other member's profile  = Part A profile in read-only
    Match settings          = the form engine again

    Genuinely new work is only the 3-tab list, the match
    card with fit score, and the match detail screen.

----------------------------------------------------------------
RISK IN THIS PHASE
----------------------------------------------------------------

    Every number above depends on something built earlier
    still working on day 24 - the card system, the form
    engine, the list component, the profile screen.

    If any of them needs rework, this phase has no room to
    absorb it.

    Matches at 1 day breaks first.
    The 8 thesis tabs are the largest item, so a wrong form
    engine hurts most there.

DONE WHEN
    - Profile saves and reloads correctly for all 8 roles
    - All 8 thesis tabs save with no data loss
    - Photo upload works
    - Dual profile create and switch work
    - All 3 match tabs load correctly

NEEDS
    Phase 4 finished and the card system working
    (the profile screen shows the user's own posts)
    Designs for profile and match screens
